# 配置表使用文档

## 1. 流程概览

```
Excel (.xlsx)
  → 一键导出.bat / ConfigExporter
  → Config/csv + Config/json
  → Card/Assets/Res/Config/*.json
  → Card/Assets/App/Config/Generated/*.cs（自动生成）
  → Unity 启动时 ConfigTables.LoadAsync
  → 业务代码读取
```

| 路径 | 说明 |
|------|------|
| `Config/*.xlsx` | 策划编辑的源表 |
| `Config/一键导出.bat` | 一键导出入口 |
| `Config/csv/` | 中间 CSV（gitignore） |
| `Config/json/` | 中间 JSON（gitignore） |
| `Card/Assets/Res/Config/*.json` | Unity 运行时 JSON |
| `Card/Assets/App/Config/` | 手写基类：`ConfigRowBase` / `ConfigConstBase` / `ConfigJson` |
| `Card/Assets/App/Config/Generated/` | **工具自动生成**的各表 `.cs`、`ConfigTables`、资源路径 |
| `Tools/ConfigExporter/` | .NET 导出工具源码 |

## 2. Excel 表规范

### 2.1 普通表（文件名不含 `Const`）

示例：`ItemConfig.xlsx`

| 行 | 含义 |
|----|------|
| 第 1 行 | 字段名（如 `Id`、`Desc`） |
| 第 2 行 | 字段类型（如 `int`、`string`、`int[]`） |
| 第 3 行 | 备注（给人看，不进 JSON） |
| 第 4 行起 | 数据（空行自动跳过） |

- 以 `#` 开头的列（如 `##var`）会被跳过，不导出。
- 工作表优先读名为 `data` 的 Sheet，否则读第一个 Sheet。

导出 JSON 为**数组**：

```json
[
  { "Id": 1010001, "Desc": "..." },
  { "Id": 1010002, "Desc": "..." }
]
```

### 2.2 常量表（文件名含 `Const`）

示例：`GameConst.xlsx`

| 列 | 含义 |
|----|------|
| 第 1 列 | 字段名 |
| 第 2 列 | 类型 |
| 第 3 列 | 备注 |
| 第 4 列 | 数据 |

- 可有表头行（如 `##var#column`、`程序中的字段名称`），会自动跳过。
- 以 `#` 开头的行会跳过。

导出 JSON 为**对象**：

```json
{
  "GameFps": 120
}
```

## 3. 支持的类型

### 标量

| 类型 | 说明 |
|------|------|
| `int` / `int32` | 整数 |
| `long` / `int64` | 长整数 |
| `float` / `single` | 单精度浮点 |
| `double` / `number` | 双精度浮点 |
| `bool` / `boolean` | 布尔（支持 `true`/`false`/`1`/`0`/`是`/`否`） |
| `string` | 字符串 |

### 数组（一维）

| 类型 | Excel 填法 | JSON |
|------|------------|------|
| `int[]` | `1\|2\|3` | `[1, 2, 3]` |
| `string[]` | `金币\|钻石` | `["金币", "钻石"]` |
| `bool[]` | `true\|0\|是` | `[true, false, true]` |
| 任意 `T[]` | 空单元格 | `[]` |

规则：

- 元素之间用 `|` 分隔（不要用逗号，会和 CSV 冲突）。
- 暂不支持二维数组（如 `int[][]`）。

## 4. 如何导出

### 方式一：一键 bat（推荐）

1. 关闭正在占用的 Excel 文件（被占用会导致读取失败）。
2. 双击 `Config/一键导出.bat`。
3. 成功后会看到：
   - `Config/csv`
   - `Config/json`
   - `Card/Assets/Res/Config`（已同步到 Unity）

### 方式二：命令行

```bash
dotnet run --project Tools/ConfigExporter -- --config Config
```

注意：纯命令行默认只写出 `Config/csv` 与 `Config/json`，**不会**自动复制到 Unity。日常请用 bat。

### 前置要求

- 已安装 .NET SDK（8.0 或兼容版本）。
- 确认 bat 退出码为 0；失败时 Unity 里仍是旧 JSON。

## 5. Unity 中如何使用

### 5.1 启动加载

`AppBootstrap` 在资源初始化之后、打开 UI 之前加载配置：

```csharp
await ConfigTables.LoadAsync(_resources.Resources);
```

`ConfigTables` 只负责加载；查询接口在各配置类基类上。

启动日志示例：

```text
[Config] loaded: GameFps=120, ItemCount=2, Item(1010001)=...
```

### 5.2 业务读取

```csharp
using App.Config;

// 常量表
int fps = GameConst.Instance.GameFps;

// 普通表：按 Id（基类 ConfigRowBase 提供）
ItemConfig item = ItemConfig.Get(1010001);
if (item != null)
{
    Debug.Log(item.Desc);
}

if (ItemConfig.TryGet(1010001, out var row))
{
    Debug.Log(row.Desc);
}

foreach (var kv in ItemConfig.All)
{
    Debug.Log($"{kv.Key}: {kv.Value.Desc}");
}
```

### 5.3 资源 Key

定义在 `ResResourcePaths`：

| 常量 | Key | 文件 |
|------|-----|------|
| `GameConst` | `Config/GameConst` | `Assets/Res/Config/GameConst.json` |
| `ItemConfig` | `Config/ItemConfig` | `Assets/Res/Config/ItemConfig.json` |

Editor 默认走 `Editor Res` 模式，改 JSON 后重新 Play 即可。  
真机 / StreamingAssets Bundle 模式需执行菜单 **`Res/Build AssetBundles`**，配置会打进 `config` bundle。

## 6. 新增一张配置表

1. 在 `Config/` 按规范新建 Excel（普通表或文件名含 `Const` 的常量表）。
2. 运行 `一键导出.bat`。
3. 工具会自动：
   - 生成 / 覆盖 `Card/Assets/App/Config/Generated/{表名}.cs`
   - 更新 `Generated/ConfigTables.cs` 加载逻辑
   - 更新 `Generated/ResResourcePaths.Config.g.cs` 资源 Key
   - 同步 JSON 到 `Card/Assets/Res/Config/`
4. Unity 刷新后即可：`XxxConfig.Get(id)` 或 `XxxConst.Instance`。

**不要手动改 `Generated/` 下的文件**，改 Excel 再导出即可。

手写部分仅限：

- `ConfigRowBase` / `ConfigConstBase` / `ConfigJson`
- 业务代码里对配置的使用

---

## 7. 修改已有字段

| 改动 | 需要做的事 |
|------|------------|
| 只改数据值 | 改 Excel → 一键导出 → Play |
| 增删/改字段名或类型 | 改 Excel → 一键导出（C# 自动更新）→ 按需改业务代码 |
| 只改备注 | 可只改 Excel；备注会进生成类的 XML 注释 |

注意：`JsonUtility` 对 JSON 里多出的字段会忽略；C# 有、JSON 没有的字段会是默认值。

## 8. 常见问题

**Q: 导出失败，提示文件被占用**  
A: 先关闭 Excel（含临时锁文件 `~$xxx.xlsx`），再重新导出。

**Q: Unity 里还是旧数据**  
A: 确认导出成功；若用 Bundle 模式，需重新 Build AssetBundles。

**Q: Editor 找不到 JSON**  
A: 确认文件在 `Assets/Res/Config/`，且 `EditorResResourceService` 已包含 `.json`。

**Q: 数组没解析成 JSON 数组**  
A: 类型列写成 `int[]` / `string[]` 等，单元格用 `|` 分隔。

**Q: 顶层数组 JsonUtility 报错**  
A: 请走 `ConfigJson.FromArrayJson<T>`（Generated 的 ConfigTables 已使用）。

**Q: 访问时报 not loaded**  
A: 确保 `ConfigTables.LoadAsync` 已在业务读取前执行（见 `AppBootstrap`）。

**Q: 能手改 Generated 里的类吗？**  
A: 不能。下次导出会覆盖。业务扩展请写在 Generated 之外。
