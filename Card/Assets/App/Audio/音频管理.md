# 音频管理

路径：`Card/Assets/App/Audio/`  
命名空间：`App.Audio`

全局 BGM 与音效由 `IAudioService` 统一播放，开关各自落盘。按钮点下音效走 `ButtonAnim` → `PlaySfx`，不再在按钮上挂 `AudioSource`。

主 BGM：`Assets/Res/Audio/BGM/BGM.mp3`（资源键 `ResResourcePaths.Bgm` = `Audio/BGM/BGM`）。  
健康游戏忠告页静音；关闭忠告进入 Home（或启动时跳过忠告直进 Home）后按存档开关开始循环播放。

---

## 1. 文件

| 文件 | 职责 |
|------|------|
| `IAudioService.cs` | 开关、播放、`ISaveFlushable` |
| `AudioService.cs` | 在 `AppServicesHost` 下挂 BGM / SFX 两个 2D `AudioSource` |

启动：`AppBootstrap` 在 `SaveFramework.Create()` 之后 `RegisterAudio` 并 `Load()`。

```csharp
var audio = AppServices.Resolve<IAudioService>();
audio.SetBgmEnabled(true);
audio.SetSfxEnabled(false);
audio.PlayBgm(clip);
audio.PlaySfx(clip);
audio.Save();
```

暂停 / 失焦 / 退出时 `AppServicesHost` 会自动 `Save()`。

---

## 2. 存档键

缺省均为开（int `1`）。

| 键 | 含义 |
|----|------|
| `audio.bgm.enabled.v1` | BGM 开关 |
| `audio.sfx.enabled.v1` | 音效开关 |

`Load()` 在启动时读入内存。`PlayBgm` / `PlaySfx` 只看内存开关，不再二次读盘。

---

## 3. 主 BGM 时序

```
启动 RegisterAudio.Load()
  → 健康忠告（不播 BGM）
  → 关闭忠告 / 跳过忠告 → 打开 Home
  → HomeViewModel.OnOpen
  → LoadAsync<AudioClip>(ResResourcePaths.Bgm)
  → PlayBgm(clip)
      开：循环播放
      关：只挂 clip，不播；之后 SetBgmEnabled(true) 会从开头或暂停处继续
```

同一 clip 再次 `PlayBgm`（例如从关卡返回 Home）不会从头重播。

关 BGM：暂停并记住曲目。再开：从暂停处继续。`PlayBgm` 换曲或 `StopBgm` 会清掉暂停状态。

---

## 4. 按钮音效

`ButtonAnim` Inspector 仍绑 `clip`。点下时：

```csharp
AppServices.Resolve<IAudioService>().PlaySfx(clip);
```

`clip` 为空、服务未就绪、或音效开关关闭：动画照常，无声。

---

## 5. 开关给界面

后续暂停 / 设置页直接绑属性即可：

```csharp
audio.SetBgmEnabled(on);
audio.SetSfxEnabled(on);
audio.Changed += RefreshToggles;
```

`BgmEnabled` / `SfxEnabled` 为当前值。
