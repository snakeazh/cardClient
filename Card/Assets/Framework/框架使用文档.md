## 1. 流程概览

```
AppBootstrap（启动场景，可销毁）
  └─ AppServices.Create()
       └─ AppServicesHost（DontDestroyOnLoad）
            └─ ServiceContainer
                 ├─ IResourceService      ← ResourceFramework.Create() + InitializeAsync
                 ├─ IAtlasService         ← AtlasService.PreloadAsync
                 ├─ ISaveService          ← SaveFramework.Create()
                 ├─ IUIManager / UIRoot   ← UIFramework.Create()
                 └─ 业务服务（GameSession、IBagService、ILevelService、IScoreService、ITalentService…）
```

| 子系统 | 路径 | 职责 |
|--------|------|------|
| DI | `Framework/UI/DI/` | 轻量容器，构造函数注入 |
| Assets | `Framework/Assets/` | 资源加载（Editor 直读 / AssetBundle） |
| UI | `Framework/UI/` | MVVM、导航、绑定、对话框、列表 |
| Save | `Framework/Save/` | 跨平台 KV 存档 |
| Log | `Framework/Log/` | 开发日志（正式包剥离 Info/Debug） |

### 启动顺序（必须遵守）

```
1. AppServices.Create()
2. ResourceFramework.Create() → await InitializeAsync() → 注册 IResourceService
3. AtlasService.PreloadAsync → 注册 IAtlasService
4. SaveFramework.Create()
5. 注册业务服务（GameSession、GameTableViewModel 等）
6. ConfigTables.LoadAsync → 注册 IBagService / ILevelService / ILevelProgressService / IScoreService / IHpService / ICourageService / IWalletService
6. ConfigTables.LoadAsync → 注册 IBagService / ILevelService / ILevelProgressService / IScoreService / IHpService / ICourageService / ITalentService
7. UIFramework.Create(container)
8. await ui.Open(首屏 ViewModel)
```

业务服务与 `SaveFramework.Create` 必须在资源初始化完成之后。  
图集预加载必须在资源初始化完成之后、打开 UI 之前。  
关卡模块、天赋模块必须在 `ConfigTables.LoadAsync` 之后注册。  
`UIFramework.Create` 要求 `IResourceService` **已注册且已 Initialize**。

## 2. DI（ServiceContainer）

路径：`Framework/UI/DI/ServiceContainer.cs`

| API | 说明 |
|-----|------|
| `RegisterInstance<T>(instance)` | 已有实例，按 `T` 注册为单例 |
| `AddSingleton<T>()` / `AddSingleton<TService, TImpl>()` | 首次 Resolve 时创建，之后复用 |
| `AddSingleton<T>(factory)` | 工厂单例 |
| `AddTransient<T>()` / `AddTransient<TService, TImpl>()` | 每次 Resolve 新建 |
| `Resolve<T>()` | 未注册抛异常 |
| `GetService(Type)` | 未注册返回 null |
| `IsRegistered(Type)` | 是否已注册 |

构造函数注入：选**参数最多**的 public 构造函数，递归解析参数类型。

```csharp
_services.Register(new GameSession());
_services.Container.AddSingleton<GameTableViewModel>();

public HomeViewModel(IUIManager ui, GameSession session, GameTableViewModel tableVm) { ... }
```

约定：

- 跨屏共享状态用 `AddSingleton`（如 `GameTableViewModel`）
- 一般 ViewModel 默认 Transient；`[AutoScreen]` 注册时若未注册会自动 `AddTransient<TVm>()`
- 跨场景解析：`AppServices.Resolve<T>()`（见 README）

## 3. 资源（IResourceService）

| 文件 | 职责 |
|------|------|
| `Framework/Assets/Runtime/ResourceFramework.cs` | `Create()` 入口 |
| `Framework/Assets/Runtime/IResourceService.cs` | 加载接口 |
| `Framework/Assets/Runtime/EditorResResourceService.cs` | Editor 直读 `Assets/Res` |
| `Framework/Assets/Runtime/AssetBundleResourceService.cs` | Android/iOS/PC 读 StreamingAssets Bundle（`LoadFromFile`） |
| `Framework/Assets/Runtime/WebGLAssetBundleResourceService.cs` | WebGL 经 HTTP 下载 Bundle（`UnityWebRequestAssetBundle`） |
| `Framework/Assets/Runtime/ResourceLoadMode.cs` | Editor 模式开关 |
| `Framework/Assets/Runtime/ResPaths.cs` | `Assets/Res` 根路径 |

### API

```csharp
_resources = ResourceFramework.Create();
await _resources.InitializeAsync();
_services.Register(_resources.Resources);

var prefab = await resources.LoadAsync<GameObject>("UI/Home");
resources.Release("UI/Home");
```

| API | 说明 |
|-----|------|
| `LoadAsync<T>(key)` | 加载，带引用计数缓存 |
| `LoadAllAsync<T>(bundleName)` | 加载该 bundle（如 `"Altas"`）内全部 T 类型资源，不入 key 缓存 |
| `LoadHandleAsync<T>(key)` | 返回 `ResourceHandle<T>`，Dispose 时 Release |
| `TryGetCached<T>(key, out asset)` | 查缓存 |
| `Release(key)` | 引用计数 -1，归零才卸载 |

### Key 规则

无扩展名路径，相对 `Assets/Res/`。应用层常量：`App/ResResourcePaths.cs`。

| Key | Editor | AssetBundle |
|-----|--------|-------------|
| `"UI/Home"` | `Assets/Res/UI/Home.prefab` | bundle `ui`（第一段小写）+ asset `Home` |

Editor 默认走直读（`EditorPrefs`：`Framework.Assets.UseEditorRes`，默认 true）。  
真机或关闭 Editor 模式：先菜单 **Res/Build AssetBundles**，从 `StreamingAssets/Bundles` 加载。

### 平台分发（`ResourceFrameworkHost.CreateBundleService`）

| 平台 | 实现 | 读取方式 |
|------|------|----------|
| Editor（直读模式） | `EditorResResourceService` | `AssetDatabase` 直读 `Assets/Res` |
| Editor（Bundle 模式）/ Android / iOS / PC | `AssetBundleResourceService` | `AssetBundle.LoadFromFile`（同步） |
| WebGL（真机） | `WebGLAssetBundleResourceService` | `UnityWebRequestAssetBundle`（HTTP 异步下载） |

注意：
- Bundle 与平台相关，打包哪个平台就先切到哪个 Build Target 再 Build AssetBundles（Android/WebGL 互不通用）。
  编辑器 Bundle 模式同理：target 是 Android 时构建的 bundle 在编辑器里 shader 会品红（shader 只含目标平台的编译产物），
  编辑器内验证需切 Standalone target 重新构建；日常迭代建议用直读模式。
- Android 上 `StreamingAssets` 在 APK 内（`jar:file://...`），运行时不能用 `System.IO` 判存在/读文件，
  只能走 `AssetBundle.LoadFromFile`；`AssetBundleResourceService` 已按此处理。
- WebGL 没有文件系统，`LoadFromFile` 不可用；所有 bundle（含 `version.txt`）经 HTTP 下载，
  部署时需保证 `StreamingAssets/Bundles` 目录可通过 URL 访问。
- 构建 AssetBundles（`Res/Build AssetBundles` 与"仅重建 AssetBundles"）按内容决定版本号：
  bundle 哈希与上次一致则版本不变（端上缓存继续有效），内容变化才递增并写入 `version.txt`；
  WebGL 下载 URL 为 `Bundles/{version}/{name}`（版本号在路径里——微信 SDK 会剥掉 query 参数
  再算缓存文件路径，`?v=` 破不了真机的 `__GAME_FILE_CACHE`），版本子目录仅 WebGL 目标拷贝；
  Android 读包内平铺目录，按 `version.txt` 判过期。
  两种布局按目标互斥只写一份：WebGL 目标只写版本子目录（平铺文件 WebGL 运行时读不到，
  写了只是翻倍包体）；非 WebGL 目标只写平铺目录。编辑器 Bundle 模式遇到 WebGL 布局会自动
  回退到 `{version}/{name}` 读取。
  不要绕过构建脚本手工替换 bundle 文件而不走构建，否则版本号不变端上会继续用缓存的旧 bundle。
- 清单 bundle 固定命名为 `Bundles`（构建时由版本名复制而来），用于解析 bundle 依赖；
  WebGL 布局下在版本子目录内，其余布局在平铺目录内。
- 自定义 shader 必须放进 `Assets/Res`（如 `Res/Shaders`，随 bundle 依赖自动加载）或加入
  Graphics Settings 的 Always Included Shaders；放在 `Resources` 里对 bundle 材质无效，会渲染成品红。

## 4. UI 框架

| 文件 | 职责 |
|------|------|
| `Framework/UI/UIFramework.cs` | `Create(container)` |
| `Framework/UI/UIManager.cs` | `IUIManager` 门面 |
| `Framework/UI/Navigation/UIRoot.cs` | 分层 Canvas，DontDestroyOnLoad |
| `Framework/UI/Navigation/UINavigator.cs` | 开/关屏幕、每层独立栈 |
| `Framework/UI/Navigation/AutoScreenAttribute.cs` | 反射自动注册 |
| `Framework/UI/View/ViewBase.cs` / `ViewModelBase.cs` | View / VM 基类 |

`UIFramework.Create` 会加载 `UI/UIRoot`、扫描 `[AutoScreen]`、注册 `IUIManager` / `IDialogService`。

### 层级（底 → 顶）

`Hud` → `Page` → `Navigation` → `Popup` → `Loading` → `TopMost`

每层独立栈：Open 会 Hide 当前栈顶；Close 弹出并恢复下一层。`Navigation` 放主界面底栏等常驻切换，盖在 Page 之上、Popup 之下；进关卡/对局时只隐藏该层，不要 Close（会 Dispose ViewModel）。

### IUIManager

```csharp
await _ui.Open(viewModel);
await _ui.Open(new ScreenId(AppScreenIds.Home), viewModel);
await _ui.Close(this);          // 关该 VM 所在层栈顶（须是栈顶）
await _ui.Close(UILayer.Popup);
```

### 新建一屏

1. Prefab 放到 `Assets/Res/UI/MyScreen.prefab`
2. `ResResourcePaths` 加 `"UI/MyScreen"`；`AppScreenIds` 加逻辑 ID
3. ViewModel 继承 `ViewModelBase`，构造函数声明依赖
4. View 继承 `ViewBase<TVm>`，根节点挂 `UIReference`，子节点挂 `UIBind`
5. 加特性并在 `OnBind` 里绑定：

```csharp
[AutoScreen(AppScreenIds.Home, UILayer.Page, ResResourcePaths.Home)]
public sealed class HomeView : ViewBase<HomeViewModel>
{
    protected override void OnBind()
    {
        Binding.BindText(UI.Get<TMP_Text>("Title"), ViewModel.Title);
        Binding.BindCommand(UI.Get<Button>("DialogButton"), ViewModel.ShowDialogCommand);
    }
}
```

6. 打开：`await _ui.Open(container.Resolve<MyViewModel>())`

参考：`App/UI/Home/HomeView.cs`、`HomeViewModel.cs`。

### 生命周期

```
Open:  SetActive → OnViewOpen → OnBind → ViewModel.OnOpen → 弹窗入场
Hide:  ViewModel.OnHide → OnViewHide → 弹窗出场 （被同层新屏盖住）
Close: 弹窗出场 → Unbind → OnViewClose → ViewModel.OnClose → Dispose
```

View 上可手动拖入 `Popup Anim`（面板 Transform）。有节点则对该节点做缩放弹窗动画；留空则瞬时显示。不要拖根节点（遮罩会跟着缩放），拖中间面板。

ViewModel 订阅用 `AddDisposable(...)`，关闭时自动释放。

| 文件 | 职责 |
|------|------|
| `Framework/UI/Binding/UIBind.cs` | 节点标记（`_key` 默认物体名；Target 可选组件 / Transform / RectTransform / GameObject） |

```csharp
Title = new ObservableProperty<string>("标题");
ShowDialogCommand = new RelayCommand(StartGame);
AddDisposable(Title.Subscribe(v => { /* ... */ }));
```

## 6. 对话框（IDialogService）

路径：`Framework/UI/Dialog/DialogService.cs`  
通过 `_ui.Dialogs` 访问。

```csharp
var result = await _ui.Dialogs.ConfirmAsync("提示", "确定退出？", DialogButtons.YesNo);
if (result == DialogResult.Yes) { ... }
```

`DialogButtons`：`Ok` / `OkCancel` / `YesNo`。  
自定义弹窗：View 用 `[AutoScreen(..., UILayer.Popup, ...)]`，然后：

```csharp
await _ui.Dialogs.ShowCustomAsync<MyDialogVm, MyResult>(vm, args);
// 弹窗 VM 内：
await _dialogs.CloseWithResult(myResult);
```

同时只能开一个 Confirm 或一个 Custom。内置确认框示例：`App/UI/Dialog/ConfirmDialogView.cs`。

## 10. 常见问题

**Q: `IResourceService is not initialized`**  
A: 先 `await InitializeAsync()`，再 `UIFramework.Create`。

**Q: Missing UIRoot**  
A: 确认 `Assets/Res/UI/UIRoot.prefab`；Bundle 模式需先 Build AssetBundles。

**Q: `UIReference missing bind key`**  
A: Inspector 点 Collect UIBinds，检查 `UIBind` 的 key 与 `UI.Get("...")` 一致。

**Q: No screen registered for ViewModel**  
A: View 缺 `[AutoScreen]`，或未手动 `RegisterScreen`。

**Q: Close(vm) 无效**  
A: 该 VM 必须是其所在层的栈顶。

**Q: Confirm already open**  
A: 上一个对话框未结束不要再开。

**Q: Editor 正常、真机加载失败**  
A: Editor 默认直读 `Assets/Res`；真机走 AB，需打 Bundle。Key 第一段会转小写作为 bundle 名。

**Q: ViewModel 状态丢了**  
A: 默认 Transient，每次 Open 新建。要共享就 `AddSingleton`。

**Q: 资源泄漏**  
A: 长生命周期用 `LoadHandleAsync` + Dispose，或成对 `Release(key)`。
