# 炸金花闯关 · 对局逻辑

本文描述当前客户端已落地的规则，供后续改玩法、调数值、接 UI 时对照。  
实现入口：`GameSession.cs`，数值：`GameDefs.cs`，牌型：`CardModel.cs`，AI：`AiBrain.cs`。  
关卡配置查询见 [`关卡模块使用文档.md`](../Level/关卡模块使用文档.md)（**尚未接入本对局**）。  
积分与玩家血量、勇气值见 [`积分与血量模块使用文档.md`](../Score/积分与血量模块使用文档.md)（**尚未接入本对局**；当前仍用 HP 下注，商店仍按剩余 HP 折金币）。

没有独立筹码。下注、奖池、全下、主池/边池全部走 **HP**。

---

## 1. 一局流程

```
发牌（玩家和存活敌人各 3 张，默认背面）
  → 选择闷注或看牌
  → 看牌后可搓牌（可取消跳过），再进入下注
  → 跟注 / 加注×2 / 加注×3 / 弃牌 / 比牌
  → 比牌 / 全下摊牌 / 连续两轮无人加注
  → 主池+边池按牌型分配 HP
  → 玩家若整体牌最大：点选敌人攻击
  → 玩家若败：承受赢家一次牌型伤害
  → 下一局 或 敌人全灭进商店
```

主路径 UI：`GameUIView` + `GameBoardController` + `CardTableAnimator`。  
`GameTableController` 是旧场景绑法，不是主路径。

## 2. 阶段 `GamePhase`

| 阶段 | 含义 |
|------|------|
| `Idle` | 未开局 |
| `WaitingLookChoice` | 发牌后：闷注或看牌 |
| `WaitingRub` | 看牌后搓牌（可取消跳过） |
| `Betting` | 下注 |
| `Showdown` | 亮牌摊牌 |
| `WaitingAttack` | 玩家胜，点选敌人攻击 |
| `RoundSettle` | 本局结束，点下一局 |
| `Shop` | 关卡胜利商店 |
| `StageFail` | 血量不足 / 阵亡，可广告借贷或复活 |
| `RunComplete` | 通关 |

## 3. 资源与平衡

货币只有 HP，没有筹码。

| 常量 | 值 | 说明 |
|------|----|------|
| `PlayerStartHp` | 4000 | 玩家每关开局满血 |
| `MinBet` / `BaseBetStart` | 10 | 每关第一手基础注 |
| `BaseBetStep` | 10 | 同一关内每手基础注 +10 |
| `RaiseLowMult` / `RaiseHighMult` | 2 / 3 | 加注 = 当前跟注 + 基础注×2 或 ×3 |
| `EnemyHp` | `2200 + stage*700` | BOSS 再 ×2.4 |
| 通关金币 | `ConvertHpToGold(剩余HP)` | 先按 `800/4000` 折成旧筹码再阶梯兑换 |

- 玩家 HP 在关卡内跨局保留，进下一关时回满。
- 敌人每关按关卡血量入场。
- 赢家吃池会 `Heal`，没有上限。
- 血量 < 当前基础注无法继续：借贷券 / 看广告借贷 / 重开关。

关卡人数：普通关 3 名敌人；每 10 关 BOSS 1 人。

---

## 4. 发牌、看牌、搓牌

- 玩家和存活敌人各发 3 张，默认背面。表现层流程见 [CardDealPoint.md](CardDealPoint.md)、[CardItem.md](CardItem.md)。
- `GameHud.dealpoint` 先叠 52 张 `CardIcon` 并播洗牌出现（用子节点 `Back`，不要关掉它），再飞到各座位落点。
- 发牌后先进入 `WaitingLookChoice`，显示 **闷注** 和 **看牌**。所有人均需至少下本手基础注。
- **闷注**立刻按当前最大档（闷注价）扣血并进入后续下注。
- **看牌**只翻玩家自己的牌：`CardItem.FlipTo(Front)` 换 `CurrentRenderer` 贴图并绕 Y 轴翻转。然后进入搓牌：点选一张滑动替换；`CancelBtn` 可跳过搓牌（仍算已看牌）。
- 搓牌结束才进入 `Betting`：跟注 / 加注×2 / 加注×3 / 弃牌 / 比牌 / 全下。看牌后按钮显示「跟注」，不再显示「闷注」。
- 看牌后该座位后续花费按看牌价（2×）计算，且必须对齐当前最大档，不能按自己更早的小注额支付。

## 5. 下注

单位始终是 **闷注档**（`StreetUnits`）。看过牌的座位付 2× HP，未看牌付 1×。跟注对齐的是当前最大档，不是某个人更早下过的小额。

### 5.1 基础注与加注后的跟注

- 每关第一手基础注 = 10，同一关内每打完一手 +10（10、20、30…）。每一手所有人至少下这个数。
- **加注成功后，本街基础跟注立刻变成加注额。** 之后所有人的跟注都按这个新档，不能再按加注前的 10/20 付。
- 下一手重新按关卡手数取基础注；边池街先回到本手基础注。

例：基础 20，加注到 60 → 后续跟注档 = 60。玩家闷着付 60；已看牌的怪物付 120；未看牌的怪物也跟 60。

### 5.2 闷 / 看牌倍率

单位是闷注档。`PaysDouble(seat) = seat.Looked`。

| 座位 | 跟注 HP |
|------|---------|
| 玩家闷 / 怪物未看牌 | 1× 当前跟注档（同样的跟注数） |
| 玩家闷、怪物已看牌 | 怪物 **2×** |
| 自己已看牌 | **2×**，且必须对齐加注后的最大档 |

词缀 `AntiRaise` 时玩家花费再 ×1.5。

### 5.3 玩家操作

| 操作 | 效果 |
|------|------|
| 闷注 / 跟注 | 补齐到当前最大档。发牌后点「闷注」；看牌后此按钮改为「跟注」 |
| 加注×2 | 目标档 = 当前跟注 + 基础注×2。例：基础 20、跟注 20 → 总 60 |
| 加注×3 | 目标档 = 当前跟注 + 基础注×3。例：基础 20、跟注 20 → 总 80 |
| 全下 `AllInBtn` | 先跟齐当轮，再把剩余 HP 全部推进奖池 |
| 弃牌 | 退出争夺，已下 HP 留在池里 |
| 比牌 | 先补齐当轮注额，然后全员亮牌 |
| 看牌 | 进入搓牌，之后自己付 2×，且必须跟上当前最大档 |

加注不够付时，能付多少付多少，视为 **全下**。点「全下」则主动把剩余血量全部投入。怪物加注同样两档；加注时能付看牌价则先看牌再加。

### 5.4 道具（每关各 1 次）

`GameUI` 的 `horBtns2` 上三个按钮始终显示：`PeekGood` / `ChaKanGood` / `TiHuanGood`。下注或搓牌阶段且仍有次数时可点，否则只禁用、不隐藏。

| 按钮 | 效果 |
|------|------|
| PeekGood | 直接再次搓牌（看牌并进入搓牌，可点选一张替换） |
| ChaKanGood | 透视：随机一名存活未弃牌敌人，翻开其随机 1 张牌 |
| TiHuanGood | 替换：自己 3 张牌全部换成牌堆新牌，并视为已看牌 |

### 5.5 连续两轮同注无人加注

当轮所有未弃牌者下注档位相同，且连续 2 轮无人加注 → 自动进入亮牌。

## 6. 亮牌与攻击

### 6.1 亮牌

所有未弃牌者亮牌，按炸金花比大小：豹子 ＞ 顺金 ＞ 金花 ＞ 顺子 ＞ 对子 ＞ 散牌。

- **玩家胜**：进入攻击结算。场上多于 1 名敌人时点选 1 人攻击；只有 1 名敌人则直接攻击。
- **玩家败**：受到赢家一次牌型伤害。多名敌人在场时，由未弃牌里牌型最高的敌人发起攻击。

### 6.2 AI 弃牌 / 亮牌

无论 AI 弃牌还是摊牌，都必须让玩家看到他的牌。AI 弃牌且场上还有其他 AI 时，立刻翻开其手牌并显示弃牌状态。

### 6.3 玩家弃牌

玩家一弃牌，剩余 AI 立刻亮牌，由牌型最高者收池并攻击玩家。不再继续边池下注。

### 6.4 全下立刻摊牌

同时满足：有人全下、本轮能跟的人都已对齐、还能继续下注的玩家 ≤ 1 → 跳过剩余轮次，立刻亮牌。

只剩玩家未弃牌（AI 全弃）→ 玩家收池并攻击，不比牌。

---

## 7. 主池 + 边池

按 TDA：任何人最多输掉自己投入的 HP。弃牌者已投入的部分仍留在对应池，但不能赢池。

### 7.1 分层

把所有座位的 `TotalBet`（含弃牌）从小到大取不重复档位：

```
主池：min(各人投入) × 投入人数
边池：上一档到下一档的差额 × 达到该档的人数
```

只有 `TotalBet >= 该档` 且 **未弃牌** 的人有资格争该池。

### 7.2 分配顺序

摊牌后从主池开始，按边池生成顺序：

1. 该池资格者里牌型最大者拿走该池
2. 牌型完全相同则平分；除不尽的 1 点给座位最靠前的人（玩家优先）
3. 最小全下者只参与主池；更大投入者可参与更多边池

### 7.3 示例

A 全下 50，B 跟 50 后再下 100，C 同样到 150：

| 池 | 金额 | 资格 |
|----|------|------|
| 主池 | 150 | A、B、C |
| 边池1 | 200 | B、C |

A 牌最大也只能拿主池 150；边池由 B/C 中牌大的一方拿走。

实现：`BuildPotLayers` / `AwardPots`。回血 `Heal`，没有上限。

## 8. 牌型与攻击

### 8.1 牌型（大 → 小）

豹子 > 顺金 > 金花 > 顺子 > 对子 > 散牌

同牌型比点数。`ChipValue`：A=14，其余为点数。这是牌力数值，不是货币。

倍率：豹子 6 / 顺金 4 / 金花 2.5 / 顺子 2 / 对子 1.5 / 散牌 1。

### 8.2 亮牌顺序

玩家先亮 → 弃牌敌人 → 未弃牌敌人。AI 弃牌当下就会翻开并显示「弃牌 + 牌型」。

### 8.3 攻击伤害

```
伤害 = 牌型基础分 × 当轮注额 × 牌型倍率 × 遗物倍率
```

用当轮注额，不用奖池总量。玩家胜则攻击：多名敌人点选 1 人，只剩 1 人直接打。玩家败则受牌型最高的赢家一次伤害。

### 8.4 破产 / 斩杀

摊牌后敌人 HP 仍 > 0 但 < `MinBet`：

- 玩家赢：视为斩杀（HP 归 0）
- 玩家输：其他敌人按奖池 15%（铁公鸡 5%）抽血救助

## 9. 商店、广告、词缀

击杀本关全部敌人 → 剩余 HP 折金币进商店。

道具 / 遗物见 `GameBalance.Catalog`。遗物最多 4 件。

广告（按钮模拟）：

- 借贷：补当前基础注
- 复活：HP 回满
- 额外搓牌：本关最多 2 次
- 双倍金币：每天最多 3 次

第 10、20… 关 BOSS 随机词缀（禁搓花色、禁计分、燧石、锋芒、透视眼、反加注、铁公鸡等）。

连续输 2 局触发「心态崩了」：下一局最大下注为当前 HP 的 50%。

## 11. 改规则时注意

1. 不要再引入独立筹码；`PlayerStartChips` 只用于金币折算。
2. 加注目标 = 当前跟注档 + 本手基础注×2 或 ×3，不要按剩余 HP 比例加注。
3. 比牌只跟当轮，不要对齐 `TotalBet`。
4. 看过牌的座位付 2×，闷注付 1×；跟注始终对齐当前最大档。
5. 全下后若 ≥2 人还能下注，必须继续边池轮，不能立刻摊牌。玩家弃牌则立刻亮牌，不打边池。
6. 结算必须按主池→边池分层，短码全下者不能拿他没投入的边池。
7. `HandScore.BaseChips` / `Card.ChipValue` 是牌力，不是 HP。
8. AI 弃牌必须立刻翻开手牌；玩家胜且只剩 1 名敌人时直接攻击，不要再点选。
