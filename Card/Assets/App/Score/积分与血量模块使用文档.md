# 积分与血量模块使用文档

路径：`Card/Assets/App/Score/`  
命名空间：`App.Score`

章节积分、**按座位**的血量、勇气值（筹码）。兑换比例读 `GameConst`：筹码→积分 `ChipsForPoints`，积分→局外资金 `ExchangePointsForGoldCoins`，均向下取整，**不清空积分**。  
积分脏标记落盘；血量与勇气值不存档。  
对局由 `GameSession` 接入：每个座位有自己的血量；攻击力读 `HeroConfig.HeroDamage` / `MonsterConfig.MonsterDamage`；玩家打出的**攻击数值** 1:1 记积分（不被怪物剩余血量截断）；关卡胜利发 `LevelConfig.GetGold` 为**局内金币**；闯关结束按积分兑**局外货币**。

局内规则见 [`GameLogic.md`](../Game/GameLogic.md)。闯关结算见 [`BattleResultPopup.md`](../UI/Popup/BattleResultPopup.md)。

## 1. 文件

| 文件 | 职责 |
|------|------|
| `IScoreService.cs` | 三种积分（`ISaveFlushable`）。局外预览 `CollectableGold`；`CollectGoldDelta` 仅存档兼容 |
| `ScoreService.cs` | 内存 + 脏标记；key `score.v1` |
| `IHpService.cs` | **按座位**血量（失败扣血 / 复活），不落盘 |
| `HpService.cs` | 内存实现，`seatId` 分账 |
| `ICourageService.cs` | **按座位**勇气值：进关换算、下注、胜负结算 |
| `CourageService.cs` | 内存实现，`seatId` 分账 |
| `ScoreModels.cs` | `ScoreSnapshot`、`ScoreBalance`、`ScoreSaveData` |

启动：`RegisterScore` 之后 `RegisterWallet`（见 `AppBootstrap`）。

```csharp
var score = AppServices.Resolve<IScoreService>();
var hp = AppServices.Resolve<IHpService>();
var courage = AppServices.Resolve<ICourageService>();
score.Save();
```

座位 Id：玩家 `0`，敌人 `1/2/3`（与 `SeatState.Id` 一致）。

## 2. 资源关系

下注不扣血。进关时用**该座位当时的当前血量**换成勇气值；下注扣勇气值。

```
进关：登记各座位血量（玩家读英雄表，怪物读关卡表）
  每回合：全场存活座位勇气值 ← 人物当前 HP
  回合下注：扣该座位勇气值（记入本回合已下注）
    成功：获得筹码 → 入账该座位勇气值；不扣血
    失败：失去本回合已下注；按伤害扣该座位血量
```

换算：`勇气值 = HP * 800 / 4000`（向下取整）。满血 4000 → 800。见 `ScoreBalance.HpToCourage`。  
每回合开始时，**玩家和存活怪物**都按**人物当前血量**换算，不按怪物自己的 HP。

| 兑换 | 字段 | 当前表值 | 公式 |
|------|------|----------|------|
| 筹码 → 积分 | `GameConst.ChipsForPoints` | 1 | `积分 = 筹码 / ChipsForPoints` |
| 积分 → 局外货币 | `GameConst.ExchangePointsForGoldCoins` | 10 | `资金 = 积分 / ExchangePointsForGoldCoins`（仅闯关结束钱包；局内金币读 `LevelConfig.GetGold`） |

## 3. 三种积分

| 字段 | 名称 | 定义 |
|------|------|------|
| `Total` | 总积分 | 从进入章节到章节结束一共获得多少积分（每一关 + 每一回合） |
| `Stage` | 关卡积分 | 当前关卡每一回合积分之和 |
| `Round` | 本轮积分 | 这一回合获得的积分 |

本轮来源：本手玩家打出的攻击数值（`ComputeAttackDamage` 公式结果），按 `GameConst.ChipsForPoints` 换成积分（当前表为 1，即攻击 100 = 100 积分）。怪物剩余血量少于攻击值时，扣血会截断，**积分仍按攻击值**。没打出攻击则本轮为 0、不向上累加。溅射按溅射攻击值计入，同样不按实际扣血。

| 调用 | 效果 |
|------|------|
| `BeginChapter` | Total / Stage / Round、已发放金币全清 |
| `BeginStage` | Stage / Round 清零，**Total 保留** |
| `BeginRound` | Round 清零，Stage / Total 保留 |
| `AwardRoundScore(chipsWon)` | 筹码按 ChipsForPoints 换成积分后写入 Round，并累加到 Stage、Total |

## 4. 关卡结算

### 胜利

玩家击败场上所有敌人后结算：发本关 `LevelConfig.GetGold` 为**局内金币**（广告双倍再发一份），积分不清空。金币可在商店买道具，然后进入下一关。

[`BattleSettleUpPop`](../UI/Popup/BattleSettleUpPop.md) 只展示**本关**：当前关卡积分 / 总积分都是 `Stage`（各回合之和），获得金币 / 提现是本关 `GetGold` 掉落（`ShopGoldGranted`）。章节累计 `Total` 不出现在这页。提现 / 双倍飞币见 [`CoinFlyFx.md`](../UI/Effects/CoinFlyFx.md)。

```csharp
var gold = Math.Max(0, levels.Current.GetGold);
Run.Gold += gold;
score.BeginStage();
hp.BeginStage(seatId, maxHp);
courage.BeginStage(seatId, hp.GetHp(seatId));
```

对局不再调用 `CollectGoldDelta()`。

### 失败

玩家血量全部扣完后结算为失败。

- 已复活：`hp.Revive(playerId)`，本关继续（不重置积分与勇气值）。
- **未复活 / 放弃**：出 [`BattleResultPopup.md`](../UI/Popup/BattleResultPopup.md) 失败页。`AgainBtn` 为广告复活；`BackBtn` 放弃回主页并兑入局外货币。

## 5. 金币与局外货币

关卡胜利发的是**局内金币** `Run.Gold`，只能在本局商店花，数量读 `LevelConfig.GetGold`。开局金币为 `GameConst.PlayerInitialGoldNum`，可加天赋富裕。

`CollectableGold = Total / GameConst.ExchangePointsForGoldCoins`（向下取整）只用于预览局外货币。**三种积分都不清空**。`CollectGoldDelta` 对局不再调用，仅存档兼容。

```csharp
var chipsWon = courage.Win(playerId, 100);
score.AwardRoundScore(chipsWon);
var gold = Math.Max(0, levels.Current.GetGold);
```

闯关结束（`RunComplete` 或放弃）把总积分按 10:1 兑成**局外货币**，写入 `IWalletService`，显示在结算页 `coinNum`。

```csharp
var funds = ScoreBalance.PointsToGold(score.Current.Total);
wallet.Add(funds);
```

| 服务 | 路径 | 存档 |
|------|------|------|
| `IWalletService` / `WalletService` | `App/Wallet/` | `wallet.gold.v1` |

## 6. 座位血量

每个座位独立。**下注不改 Hp。**

| API | 说明 |
|------|------|
| `BeginStage(seatId, maxHp, hp=-1)` | 登记满血；`hp&lt;0` 时当前血=满血 |
| `GetHp` / `GetMaxHp` | 读该座位 |
| `Damage(seatId, amount)` | **攻击结算**扣血，最低 0 |
| `Heal(seatId, amount)` | 回血，无上限 |
| `Revive(seatId)` | Hp = 该座位 MaxHp，不改勇气值 |
| `IsDead(seatId)` | Hp &lt;= 0 |

桌面上的 `SeatState.Hp` / `MaxHp` 与服务同步。HUD 心脏显示血量。

---

## 7. 座位勇气值

| API | 说明 |
|------|------|
| `BeginStage(seatId, hp)` | 用该座位当前血量换算可用勇气值，已下注清零 |
| `BeginRound(seatId)` | 已下注清零，可用额保留 |
| `TryBet(seatId, amount)` | 从可用额扣到本回合已下注 |
| `Add(seatId, amount)` | 入账筹码，不清已下注（吃池） |
| `Win(seatId, chipsWon)` | 成功：筹码入账，清已下注 |
| `Lose(seatId)` | 失败：已下注作废，返回失去数量 |

`SeatState.Courage` / `CourageStake` 与服务同步。HUD 筹码显示勇气值。

## 8. 对局接入点

| 时机 | 调用 |
|------|------|
| `StartNewRun` / `RestartChallenge` | `score.BeginChapter()`，各座位 `hp.BeginStage` + `courage.BeginStage` |
| `StartStage`（下一关） | `score.BeginStage()`，各座位按各自 MaxHp 换算勇气值 |
| 每局发牌前 | `score.BeginRound()`，各存活座位按人物当前 HP 换算勇气值 |
| 跟注 / 加注 / 全下 | `courage.TryBet(seatId, amount)`（扣勇气值） |
| 回合成功吃池 | `courage.Add` / `Win`，玩家再 `score.AwardRoundScore` |
| 回合失败 | `courage.Lose`，`hp.Damage`（攻击伤害） |
| 血量扣完且复活 | `hp.Revive(playerId)`，勇气值保留 |
| 勇气值不够下一手 | 借贷加勇气值，不改血量 |
