# 启动流程

路径：`Card/Assets/App/Bootstrap/`  
命名空间：`App.Bootstrap`  
忠告页：`App.UI.Splash`

冷启动分两段：**最小初始化**（能开忠告页）与 **重型初始化**（图集 / 配置表 / 业务服务 / 登录）。  
首页与选关依赖重型阶段注册的服务（如 `TalentBonusManager`），**重型未成功完成前禁止进首页**。

---

## 1. 文件

| 文件 | 职责 |
|------|------|
| `AppBootstrap.cs` | 入口：建 `AppServicesHost`、最小初始化、开忠告或直接重型初始化 |
| `AppServices.cs` / `AppServicesHost.cs` | 全局 DI 容器与落盘宿主 |
| `LaunchInitialization.cs` | 重型初始化完成信号（`Complete` / `Fail`） |
| [`../UI/Splash/HealthAdvisoryViewModel.cs`](../UI/Splash/HealthAdvisoryViewModel.cs) | 忠告展示；等倒计时与重型初始化都完成后再进首页 |
| [`../UI/Splash/HealthAdvisoryPolicy.cs`](../UI/Splash/HealthAdvisoryPolicy.cs) | 是否展示忠告（当前始终展示） |

---

## 2. 时序

```
AppBootstrap.Start
  ├─ 最小初始化：Resource / Save / Wallet / Energy / GameSession / UIFramework / Toast
  ├─ 注册 LaunchInitialization
  └─ 若展示忠告
        ├─ Open(HealthAdvisoryViewModel)          ← 先占资源加载
        └─ fire-and-forget RunHeavyInitAsync      ← 与忠告倒计时并发
     否则
        ├─ await RunHeavyInitAsync
        └─ OpenHomeWithNavigation
```

忠告页：

```
HealthAdvisory.OnOpen → RunFlowAsync
  await WhenAll(展示倒计时, LaunchInitialization.Completion)
  ├─ 成功 → EnterHomeAsync（开 Home + Navigation + MainResource）
  └─ 失败 → 打根异常 +「启动失败」对话框，不进首页
```

`RunHeavyInitAsync`：成功 `launchInit.Complete()`；异常 `launchInit.Fail(ex)` 再抛出。

---

## 3. 重型初始化顺序（节选）

`InitializeHeavyAsync` 内与 DI 相关的关键顺序：

| 步骤 | 注册 / 动作 |
|------|-------------|
| 图集 / 阴影 / 攻击调参 | `RegisterAtlas` 等 |
| 音频 | `IAudioService` |
| **配置表** | `ConfigTables.LoadAsync`（其后才能建依赖表的服务） |
| 背包 / 关卡 / 积分血量 | `RegisterBag` / `RegisterLevel` / `RegisterScore` |
| **天赋** | `RegisterTalent` → `ITalentService` + **`TalentBonusManager`** |
| 广告商店 / 抖音奖励 / 解锁 / 引导 | … |
| 登录 | `ConnectAndPrepareAsync`（失败弹重试，成功才算完成） |
| 预热 | 选关列表项 / 卡槽对象池 |

`HomeViewModel` / `LevelUIViewModel` 构造注入 `TalentBonusManager`。  
该服务只在 `RegisterTalent` 之后存在；更早创建它们会报：

`InvalidOperationException: Service not registered: App.Talent.TalentBonusManager`

---

## 4. 硬规则：初始化失败不进首页

错误做法（已废弃）：忠告页 `catch` 里仍 `EnterHomeAsync`。  
重型若在 `RegisterTalent` 之前失败，进首页会先炸在 `TalentBonusManager` 未注册，**掩盖图集 / 配置表等真正根因**。

正确做法：

1. `WhenAll` 等到 `LaunchInitialization` **成功** 才进首页  
2. 失败时解包 `AggregateException`，`AppLog` 根异常，弹「启动失败」，留在忠告页  
3. 排查时看 Console 里**更早**的那条异常，不要只盯 DI 未注册
