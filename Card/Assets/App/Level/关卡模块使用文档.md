# 关卡模块使用文档

路径：`Card/Assets/App/Level/`  
命名空间：`App.Level`

读 `LevelConfig` / `MonsterGroupConfig` / `MonsterConfig`，给出关卡快照；另存已通关难度。  
**尚未接入 `GameSession`**：对局仍用 `GameBalance` 硬编码人数与血量。

---

## 1. 文件

| 文件 | 职责 |
|------|------|
| `ILevelService.cs` | 关卡查询、当前选中关卡 |
| `LevelService.cs` | 启动建索引、解析怪物组、当前关卡 Id |
| `LevelModels.cs` | `LevelSnapshot` / `LevelMonster` / `LevelProgressSaveData` |
| `ILevelProgressService.cs` | 通关进度接口（`ISaveFlushable`） |
| `LevelProgressService.cs` | 已通关难度：内存 + 脏标记落盘 |

启动：`ConfigTables.LoadAsync` 之后 `RegisterLevel`（见 `AppBootstrap`）。

```csharp
var level = AppServices.Resolve<ILevelService>();
var progress = AppServices.Resolve<ILevelProgressService>();
```

---

## 2. 配置关系

```
LevelConfig.MonsterGroup[]  →  MonsterGroupConfig
MonsterGroupConfig.MonsterId + MonsterLevel  →  MonsterConfig
```

| 表 | 关键字段 | 用法 |
|----|----------|------|
| `LevelConfig` | `Id`、`Difficulty`、`Level`、`MonsterGroup[]` | 一关 = 某难度下的第 N 关 |
| `MonsterGroupConfig` | `MonsterId`、`MonsterLevel` | 关卡里的一个上场槽 |
| `MonsterConfig` | `MonsterId`、`MonsterLevel`、`Type`、`MonsterHp`、`MonsterEntry` | 用 `(MonsterId, MonsterLevel)` 联查，不用猜行 `Id` |

现有数据：难度 1–5 × 每档 10 关；每关 1–3 个怪物组；第 10 关含 `Type=Boss`。  
`MonsterEntry` 原样带到 `LevelMonster`，本模块不解释、不接 `BossAffix`。

推进约定：**单局只打当前难度**（`DefaultDifficulty = 1`）。`TryGetNext` 为 false 表示该难度打完。不跨难度。

---

## 3. 索引

`LevelService` 构造时扫三张表，建成嵌套字典：

```
_levels[难度][关卡号]     → LevelSnapshot
_levelsById[LevelConfig.Id] → LevelSnapshot
_monsters[怪物Id][等级]    → LevelMonster
```

缺组、缺怪、一组超过 3 个槽（`MaxMonstersPerLevel = 3`）：`LogWarning`，不抛。超过 3 个只取前 3 个。

---

## 4. ILevelService

```csharp
int DefaultDifficulty { get; }                    // 1
int CurrentLevelId { get; }                       // 当前选中的 LevelConfig.Id，未选为 0
LevelSnapshot Current { get; }                    // CurrentLevelId 对应快照，没有则 null

int GetMaxLevel(int difficulty);                  // 该难度最大关卡号，没有则 0
IReadOnlyList<int> GetDifficulties();             // 配置中全部难度，升序

bool TryGet(int difficulty, int level, out LevelSnapshot snapshot);
LevelSnapshot Get(int difficulty, int level);     // 没有则 null

bool TryGetNext(int difficulty, int level, out LevelSnapshot next); // 同难度 level+1

bool TryGetById(int levelId, out LevelSnapshot snapshot);
LevelSnapshot GetById(int levelId);               // LevelConfig.Id，没有则 null

bool TrySelect(int levelId);                      // 按 Id 选中；未知则 Warning，保持原值
bool TrySelect(int difficulty, int level);        // 按难度+关卡号选中；没有则 Warning

bool TryGetMonster(int monsterId, int monsterLevel, out LevelMonster monster);
```

启动时默认选中 `DefaultDifficulty` 第 1 关。只存在内存里，不落盘。Home 点难度会 `TrySelect(difficulty, 1)`。

```csharp
var level = AppServices.Resolve<ILevelService>();
level.TrySelect(2, 1);            // 选中难度 2 第 1 关
var snapshot = level.Current;     // 或 GetById(level.CurrentLevelId)
var byId = level.GetById(1010);

if (level.TryGetNext(snapshot.Difficulty, snapshot.Level, out var next))
{
    level.TrySelect(next.Id);     // 推进到下一关
}
```

### LevelSnapshot

| 字段 | 说明 |
|------|------|
| `Id` | `LevelConfig.Id` |
| `Difficulty` | 难度 |
| `Level` | 该难度下的关卡号 |
| `HasBoss` | 任一怪物 `Type == MonsterType.Boss` |
| `Monsters` | 上场顺序 = 座位 0..n-1，最多 3 |

### LevelMonster

| 字段 | 说明 |
|------|------|
| `GroupId` | `MonsterGroupConfig.Id` |
| `MonsterId` / `MonsterLevel` | 联查键 |
| `Type` / `IsBoss` | `MonsterType.Normal` / `Boss` |
| `Hp` | `MonsterConfig.MonsterHp` |
| `MonsterEntry` | 机制 id，暂不解释 |

## 5. 通关进度（ILevelProgressService）

存档 key：`level.progress.v1`。磁盘上只存 **已通关的难度列表**（`int[] ClearedDifficulties`）。

外部传入刚打完的 **关卡 Id**（`LevelConfig.Id`）。内部 `GetById` 后看 `TryGetNext`：只有该关是该难度最后一关，才把该难度写入进度。

```
MarkCleared(levelId)
  → 未知 Id：Warning，不写
  → 有下一关：不写
  → 最后一关且该难度尚未记录：写入难度，标脏
```

```csharp
var progress = AppServices.Resolve<ILevelProgressService>();
progress.MarkCleared(1010); // 难度 1 第 10 关 → 写入难度 1
progress.MarkCleared(1005); // 中间关 → 不写
if (progress.IsCleared(1)) { /* 难度 1 已通关 */ }
var all = progress.GetClearedDifficulties(); // 升序
progress.Save();
```

| API | 说明 |
|-----|------|
| `IsCleared(difficulty)` | 该难度是否已通关 |
| `MarkCleared(levelId)` | 报关卡 Id；仅最后一关写入难度 |
| `GetClearedDifficulties()` | 已通关难度，升序 |
| `Clear()` | 清空进度 |
| `Load()` / `Save()` | 读档 / 仅 dirty 时刷盘 |

`MarkCleared` / `Clear` 只改内存并标脏，**不立即 IO**。落盘与背包相同：

1. 业务主动 `Save()`（推荐：通关结算）
2. `AppServicesHost` 自动：暂停、失焦、退出、销毁

未知关卡 Id、存档里未知难度会 Warning。进度服务实现 `ISaveFlushable`，注册到 Host 后会自动刷盘。
