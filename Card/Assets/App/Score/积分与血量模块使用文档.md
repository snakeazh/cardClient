# 积分与血量模块使用文档

路径：`Card/Assets/App/Score/`  
命名空间：`App.Score`

章节积分、玩家血量、勇气值（筹码）。兑换比例读 `GameConst`：筹码→积分 `ChipsForPoints`，积分→金币 `ExchangePointsForGoldCoins`，均向下取整，**不清空积分**。  
积分脏标记落盘；血量与勇气值不存档。  
**尚未接入 `GameSession`**：对局仍用座位 HP 下注，商店仍按 `GameBalance.ConvertHpToGold(剩余HP)`。

## 2. 资源关系

下注不扣血。进关时用**当时的当前血量**换成勇气值；下注扣勇气值。

```
进关：当前 HP → 勇气值
  回合下注：扣勇气值（记入本回合已下注）
    成功：获得筹码 → 入账勇气值，并按 ChipsForPoints 记本轮积分；不扣血
    失败：失去本回合已下注；按伤害扣血
```

换算：`勇气值 = HP * 800 / 4000`（向下取整）。满血 4000 → 800。见 `ScoreBalance.HpToCourage`。

| 兑换 | 字段 | 当前表值 | 公式 |
|------|------|----------|------|
| 筹码 → 积分 | `GameConst.ChipsForPoints` | 1 | `积分 = 筹码 / ChipsForPoints` |
| 积分 → 金币 | `GameConst.ExchangePointsForGoldCoins` | 10 | `金币 = 积分 / ExchangePointsForGoldCoins` |

---

## 3. 三种积分

| 字段 | 名称 | 定义 |
|------|------|------|
| `Total` | 总积分 | 从进入章节到章节结束一共获得多少积分（每一关 + 每一回合） |
| `Stage` | 关卡积分 | 当前关卡每一回合积分之和 |
| `Round` | 本轮积分 | 这一回合获得的积分 |

本轮来源：回合**成功**获得的筹码 / `GameConst.ChipsForPoints`（向下取整）。当前表为 1，即 1 筹码 = 1 积分。失败本轮为 0、不向上累加。

| 调用 | 效果 |
|------|------|
| `BeginChapter` | Total / Stage / Round、已发放金币全清 |
| `BeginStage` | Stage / Round 清零，**Total 保留** |
| `BeginRound` | Round 清零，Stage / Total 保留 |
| `AwardRoundScore(chipsWon)` | 筹码按 ChipsForPoints 换成积分后写入 Round，并累加到 Stage、Total |

## 4. 关卡结算

### 胜利

玩家击败场上所有敌人后结算：将**总积分**按 `GameConst.ExchangePointsForGoldCoins` 换成金币（向下取整；当前表为 10，即 699 → 69），积分不清空。金币可在商店买道具，然后进入下一关。

```csharp
var gold = score.CollectGoldDelta(); // 本章节可收取金币的差额
Run.Gold += gold;
// 商店结束后：
score.BeginStage();
hp.BeginStage();
courage.BeginStage(hp.Hp);
```

多关连续胜利时，每关只发「总积分/10 − 本章节已发放」的差额，避免按总积分重复加钱。

### 失败

玩家血量全部扣完后结算为失败。

- 已复活：`hp.Revive()`，本关继续（不重置积分）。
- **未复活**：下次进入从**当前章节第一关**重开：`score.BeginChapter()` 清三种积分与已发放金币；`hp.BeginStage()` 回满；`courage.BeginStage(hp.Hp)`。选关回到该章节第 1 关由关卡模块负责（尚未接入）。

## 5. 金币

`CollectableGold = Total / GameConst.ExchangePointsForGoldCoins`（向下取整）。**三种积分都不清空**。

关卡胜利只通过 `CollectGoldDelta()` 发金。

```csharp
score.AwardRoundScore(courage.Win(100)); // 100 筹码 / ChipsForPoints → 本轮积分
var gold = score.CollectGoldDelta();
```

## 6. 玩家血量

只管玩家。敌人 HP 仍在 `SeatState`。**下注不改 Hp。**

| API | 说明 |
|------|------|
| `BeginStage` | Hp = MaxHp（进关回满，再拿 `hp.Hp` 去换勇气值） |
| `Damage(amount)` | **回合失败**扣血，最低 0 |
| `Heal(amount)` | 借贷等回血，无上限；胜利吃池不走这里 |
| `Revive` | Hp = MaxHp |
| `IsDead` | Hp &lt;= 0 |

---

## 7. 勇气值

| API | 说明 |
|------|------|
| `BeginStage(hp)` | 用当前血量换算可用勇气值，已下注清零 |
| `BeginRound` | 已下注清零，可用额保留 |
| `TryBet(amount)` | 从可用额扣到本回合已下注 |
| `Win(chipsWon)` | 成功：筹码入账，清已下注，返回入账数量 |
| `Lose` | 失败：已下注作废（下注时已从可用额扣除），返回失去数量 |

## 8. 对局接入点（尚未调用）

| 时机 | 调用 |
|------|------|
| `StartNewRun` / 失败未复活重开章节 | `score.BeginChapter()`，`hp.BeginStage()`，`courage.BeginStage(hp.Hp)` |
| `StartStage`（下一关） | `score.BeginStage()`，`hp.BeginStage()`，`courage.BeginStage(hp.Hp)` |
| 每局发牌前 | `score.BeginRound()`，`courage.BeginRound()` |
| 跟注 / 加注 / 全下 | `courage.TryBet(amount)` |
| 回合成功 | `score.AwardRoundScore(courage.Win(chipsWon))`，不扣血 |
| 回合失败 | `courage.Lose()`，`hp.Damage(amount)` |
| 敌人全灭（关卡胜利） | `Run.Gold += score.CollectGoldDelta()`，进商店，再 `BeginStage` 进下一关 |
| 血量扣完且复活 | `hp.Revive()`，本关继续 |
| 血量扣完且未复活 | `score.BeginChapter()`，`hp.BeginStage()`，`courage.BeginStage(hp.Hp)`，从章节第一关重开 |
