# 天赋模块使用文档

路径：`Card/Assets/App/Talent/`  
命名空间：`App.Talent`

读 `TalentConfig` / `TalentEntryConfig`，按天赋 Id 记获得次数，每获得 **1** 次升 1 级。  
对局效果尚未接入 `GameSession`。

配置表规范见 [`配置表使用文档.md`](../../../../Config/配置表使用文档.md)。  
日志见 [`日志使用文档.md`](../../Framework/Log/日志使用文档.md)。

## 2. 配置关系

```
TalentConfig (TalentId + TalentLevel)  →  TalentEntryConfig
```

| 表 | 关键字段 | 用法 |
|----|----------|------|
| `TalentConfig` | `TalentId`、`TalentLevel`、`TalentEntry` | 同一天赋 Id 多行，一行一个等级 |
| `TalentEntryConfig` | `Type`、`Value` | 机制词条。本模块只挂到快照上，不结算 |

现有数据：天赋 Id `101`–`112`，每档 1–10 级。  
`TalentConfig.Get(rowId)` 按行 `Id`（如 `10101`）查，不要拿来当天赋 Id。等级查询走本模块的 `Get(talentId, level)`。

---

## 3. 等级规则

`TalentBalance.CopiesPerLevel = 1`。等级由获得次数推导，不单独存档：

```
Level = min(MaxLevel, Count)
```

| 获得次数 | 等级 | 距下级 |
|----------|------|--------|
| 0 | 0（未解锁） | 还差 1 |
| 1 | 1 | 还差 1 |
| 2 | 2 | … |
| 10 | 10（满级，现表上限） | 0 |

满级后再获得仍记入 `Count`，等级不再涨。

## 4. ITalentService

```csharp
var talent = AppServices.Resolve<ITalentService>();
var ids = talent.GetIds();                 // 配置中全部天赋 Id，升序
var max = talent.GetMaxLevel(101);         // 10
var result = talent.Add(101);              // 获得 1 个 → 升到 1 级
talent.Add(101, 2);                        // 一次获得 2 个 → 连升 2 级
var snapshot = talent.GetCurrent(101);
if (snapshot.IsOwned) { /* 已解锁 */ }
if (result.LeveledUp) { /* 刚升级 */ }
talent.Save();
```

| API | 说明 |
|-----|------|
| `GetIds()` | 配置中的天赋 Id，升序 |
| `GetMaxLevel(id)` | 该 Id 最大等级，没有则 0 |
| `GetCount(id)` | 已获得次数 |
| `GetLevel(id)` | 当前等级，未解锁为 0 |
| `IsOwned` / `IsMaxLevel` | 是否已解锁 / 是否满级 |
| `TryGet(id, level, out row)` | 查该等级的 `TalentConfig` 行 |
| `GetCurrent(id)` | 当前等级快照（未知 Id 也返回未解锁快照） |
| `GetOwned()` | 已解锁（等级 > 0）的快照 |
| `Add(id, amount=1)` | 获得次数；返回升级前等级与当前快照 |
| `Clear()` | 清空进度 |
| `Load()` / `Save()` | 读档 / 仅 dirty 时刷盘 |

未知天赋 Id、存档里未知 Id 会 `AppLog.Warn(LogChannel.Talent)`，次数仍写入。`amount <= 0` 抛异常。

`Add` / `Clear` 只改内存并标脏，**不立即 IO**。落盘与背包相同：

1. 业务主动 `Save()`（推荐：获得结算）
2. `AppServicesHost` 自动：暂停、失焦、退出、销毁

## 5. TalentSnapshot

| 字段 | 说明 |
|------|------|
| `TalentId` / `Count` / `Level` / `MaxLevel` | 身份与进度 |
| `CopiesTowardNext` | 已计入下一级的次数（每次获得都正好升一级，未满级时为 0） |
| `CopiesNeededForNext` | 升到下一级还差几个（满级为 0） |
| `IsOwned` / `IsMaxLevel` | 等级 &gt; 0 / 已达最大 |
| `Config` | 当前等级的 `TalentConfig`，未解锁为 null |
| `Entry` | 当前行的 `TalentEntryConfig`，没有则为 null |

`TalentAddResult.LeveledUp` 为本次 `Add` 是否升了级。
