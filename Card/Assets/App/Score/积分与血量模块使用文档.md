# 积分与血量模块使用文档

路径：`Card/Assets/App/Score/`  
命名空间：`App.Score`

章节积分、**按座位**的血量、勇气值（筹码）。兑换比例读 `GameConst`：筹码→积分 `ChipsForPoints`，积分→金币 `ExchangePointsForGoldCoins`，均向下取整，**不清空积分**。  
积分脏标记落盘；血量与勇气值不存档。  
对局由 `GameSession` 接入：每个座位有自己的血量；每手按该座位当前血量换算攻击力；玩家对怪造成的总伤害 1:1 记积分；通关按总积分换金币。

---

## 1. 文件

| 文件 | 职责 |
|------|------|
| `IScoreService.cs` | 三种积分、可收取金币、差额发放（`ISaveFlushable`） |
| `ScoreService.cs` | 内存 + 脏标记；key `score.v1` |
| `IHpService.cs` | **按座位**血量（失败扣血 / 复活），不落盘 |
| `HpService.cs` | 内存实现，`seatId` 分账 |
| `ICourageService.cs` | **按座位**勇气值：进关换算、下注、胜负结算 |
| `CourageService.cs` | 内存实现，`seatId` 分账 |
| `ScoreModels.cs` | `ScoreSnapshot`、`ScoreBalance`、`ScoreSaveData` |

启动：`RegisterLevel` 之后 `RegisterScore`（见 `AppBootstrap`）。

```csharp
var score = AppServices.Resolve<IScoreService>();
var hp = AppServices.Resolve<IHpService>();
var courage = AppServices.Resolve<ICourageService>();
score.Save();
```

座位 Id：玩家 `0`，敌人 `1/2/3`（与 `SeatState.Id` 一致）。

## 2. 资源关系

下注不扣血。进关时用**该座位当时的当前血量**换成勇气值；下注扣勇气值。

```
进关：登记各座位血量（玩家读英雄表，怪物读关卡表）
  每回合：全场存活座位勇气值 ← 人物当前 HP
  回合下注：扣该座位勇气值（记入本回合已下注）
    成功：获得筹码 → 入账该座位勇气值；不扣血
    失败：失去本回合已下注；按伤害扣该座位血量
```

换算：`勇气值 = HP * 800 / 4000`（向下取整）。满血 4000 → 800。见 `ScoreBalance.HpToCourage`。  
每回合开始时，**玩家和存活怪物**都按**人物当前血量**换算，不按怪物自己的 HP。

| 兑换 | 字段 | 当前表值 | 公式 |
|------|------|----------|------|
| 筹码 → 积分 | `GameConst.ChipsForPoints` | 1 | `积分 = 筹码 / ChipsForPoints` |
| 积分 → 金币 | `GameConst.ExchangePointsForGoldCoins` | 10 | `金币 = 积分 / ExchangePointsForGoldCoins` |

## 3. 三种积分

| 字段 | 名称 | 定义 |
|------|------|------|
| `Total` | 总积分 | 从进入章节到章节结束一共获得多少积分（每一关 + 每一回合） |
| `Stage` | 关卡积分 | 当前关卡每一回合积分之和 |
| `Round` | 本轮积分 | 这一回合获得的积分 |

本轮来源：本手玩家对怪造成的总伤害，按 `GameConst.ChipsForPoints` 换成积分（当前表为 1，即伤害 100 = 100 积分）。没打出伤害则本轮为 0、不向上累加。

| 调用 | 效果 |
|------|------|
| `BeginChapter` | Total / Stage / Round、已发放金币全清 |
| `BeginStage` | Stage / Round 清零，**Total 保留** |
| `BeginRound` | Round 清零，Stage / Total 保留 |
| `AwardRoundScore(chipsWon)` | 筹码按 ChipsForPoints 换成积分后写入 Round，并累加到 Stage、Total |

## 4. 关卡结算

### 胜利

玩家击败场上所有敌人后结算：将**总积分**按 `GameConst.ExchangePointsForGoldCoins` 换成金币（向下取整；当前表为 10，即 699 → 69），积分不清空。金币可在商店买道具，然后进入下一关。

```csharp
var gold = score.CollectGoldDelta();
Run.Gold += gold;
score.BeginStage();
hp.BeginStage(seatId, maxHp);
courage.BeginStage(seatId, hp.GetHp(seatId));
```

多关连续胜利时，每关只发「总积分/10 − 本章节已发放」的差额，避免按总积分重复加钱。

### 失败

玩家血量全部扣完后结算为失败。

- 已复活：`hp.Revive(playerId)`，本关继续（不重置积分与勇气值）。
- **未复活**：下次进入从**当前章节第一关**重开：`score.BeginChapter()`；各座位 `hp.BeginStage` 回满并 `courage.BeginStage`。

---

## 5. 金币

`CollectableGold = Total / GameConst.ExchangePointsForGoldCoins`（向下取整）。**三种积分都不清空**。

关卡胜利只通过 `CollectGoldDelta()` 发金。

```csharp
var chipsWon = courage.Win(playerId, 100);
score.AwardRoundScore(chipsWon);
var gold = score.CollectGoldDelta();
```

## 6. 座位血量

每个座位独立。**下注不改 Hp。**

| API | 说明 |
|------|------|
| `BeginStage(seatId, maxHp, hp=-1)` | 登记满血；`hp&lt;0` 时当前血=满血 |
| `GetHp` / `GetMaxHp` | 读该座位 |
| `Damage(seatId, amount)` | **攻击结算**扣血，最低 0 |
| `Heal(seatId, amount)` | 回血，无上限 |
| `Revive(seatId)` | Hp = 该座位 MaxHp，不改勇气值 |
| `IsDead(seatId)` | Hp &lt;= 0 |

桌面上的 `SeatState.Hp` / `MaxHp` 与服务同步。HUD 心脏显示血量。

---

## 7. 座位勇气值

| API | 说明 |
|------|------|
| `BeginStage(seatId, hp)` | 用该座位当前血量换算可用勇气值，已下注清零 |
| `BeginRound(seatId)` | 已下注清零，可用额保留 |
| `TryBet(seatId, amount)` | 从可用额扣到本回合已下注 |
| `Add(seatId, amount)` | 入账筹码，不清已下注（吃池） |
| `Win(seatId, chipsWon)` | 成功：筹码入账，清已下注 |
| `Lose(seatId)` | 失败：已下注作废，返回失去数量 |

`SeatState.Courage` / `CourageStake` 与服务同步。HUD 筹码显示勇气值。

---

## 8. 对局接入点

| 时机 | 调用 |
|------|------|
| `StartNewRun` | `score.BeginChapter()`，各座位 `hp.BeginStage` + `courage.BeginStage` |
| `StartStage`（下一关） | `score.BeginStage()`，各座位按各自 MaxHp 换算勇气值 |
| 每局发牌前 | `score.BeginRound()`，各存活座位按人物当前 HP 换算勇气值 |
| 跟注 / 加注 / 全下 | `courage.TryBet(seatId, amount)`（扣勇气值） |
| 回合成功吃池 | `courage.Add` / `Win`，玩家再 `score.AwardRoundScore` |
| 回合失败 | `courage.Lose`，`hp.Damage`（攻击伤害） |
| 血量扣完且复活 | `hp.Revive(playerId)`，勇气值保留 |
| 勇气值不够下一手 | 借贷加勇气值，不改血量 |
