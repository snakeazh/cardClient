# 炸金花闯关 · 对局逻辑

本文描述当前客户端已落地的规则，供后续改玩法、调数值、接 UI 时对照。  
实现入口：`GameSession.cs`，数值：`GameDefs.cs`，牌型：`CardModel.cs`，AI：`AiBrain.cs`。

没有独立筹码。下注、奖池、全下、主池/边池全部走 **HP**。

---

## 1. 一局流程

```
发牌（各 3 张，默认背面）
  → 先选看牌或取消（取消=闷注）
  → 看牌后搓牌（可取消跳过搓牌），再进入下注（跟注/加注/弃牌/比牌，不再显示闷注）
  → 比牌 / 全下摊牌 / 连续两轮无人加注
  → 主池+边池按牌型分配 HP
  → 玩家若整体牌最大：点选敌人攻击
  → 玩家若败：承受赢家一次牌型伤害
  → 下一局 或 敌人全灭进商店
```

主路径 UI：`GameUIView` + `GameBoardController` + `CardTableAnimator`。  
`GameTableController` 是旧场景绑法，不是主路径。

## 2. 阶段 `GamePhase`

| 阶段 | 含义 |
|------|------|
| `Idle` | 未开局 |
| `WaitingLookChoice` | 发牌后：看牌或取消（闷注） |
| `WaitingRub` | 看牌后搓牌（可取消跳过） |
| `Betting` | 下注 |
| `Showdown` | 亮牌摊牌 |
| `WaitingAttack` | 玩家胜，点选敌人攻击 |
| `RoundSettle` | 本局结束，点下一局 |
| `Shop` | 关卡胜利商店 |
| `StageFail` | 血量不足 / 阵亡，可广告借贷或复活 |
| `RunComplete` | 通关 |

## 3. 资源与平衡

货币只有 HP，没有筹码。

| 常量 | 值 | 说明 |
|------|----|------|
| `PlayerStartHp` | 4000 | 玩家每关开局满血 |
| `MinBet` | 50 | 第 1 轮单注 |
| `EnemyHp` | `2200 + stage*700` | BOSS 再 ×2.4 |
| 通关金币 | `ConvertHpToGold(剩余HP)` | 先按 `800/4000` 折成旧筹码再阶梯兑换 |

- 玩家 HP 在关卡内跨局保留，进下一关时回满。
- 敌人每关按关卡血量入场。
- 赢家吃池会 `Heal`，没有上限。
- 血量 < `MinBet` 无法继续：借贷券 / 看广告借贷 / 重开关。

关卡人数：普通关 3 名敌人；每 10 关 BOSS 1 人。

---

## 4. 发牌、看牌、搓牌

- 玩家和存活敌人各发 3 张，默认背面。
- 发牌后先进入 `WaitingLookChoice`，只显示 **看牌** 和 **取消**。
- **取消** = 闷注，立刻按当轮单注扣血并进入后续下注。
- **看牌**只翻玩家自己的牌，然后进入搓牌：点选一张滑动替换；`CancelBtn` 可跳过搓牌（仍算已看牌）。
- 搓牌结束才进入 `Betting`：跟注 / 加注 / 弃牌 / 比牌 / 全下。看牌后按钮显示「跟注」，不再显示「闷注」。
- 看牌后本局该座位后续花费按「看牌」计算（见下注倍率）。

---

## 5. 下注

### 5.1 当轮单注 `_betStep`

- 第 1 轮单注 = `MinBet`（50）。
- 一轮结束时：`_betStep = 本轮最终注额`。
- 下一轮跟注、加注幅度都用这个值（**上一轮的下注量**）。
- 例：第 1 轮单注 50，加注到 100 → 第 2 轮跟注 100，再加注 +100 到 200。

比牌、跟注对齐的是 **当轮注额**（`StreetUnits` / `_betStep`），不是累计 `TotalBet`。  
界面「下注」显示当轮已付 `StreetPaid`。

### 5.2 闷 / 看牌倍率

花费按「单注单位」再乘倍率，两边对齐的是同一档单位：

| 你的状态 | 你付 | 对手付 |
|----------|------|--------|
| 闷（未看牌） | 1× | **2×** |
| 看牌 | 2× | 1× |

实现：`PaysDouble`。词缀 `AntiRaise` 时玩家花费再 ×1.5。

### 5.3 玩家操作

| 操作 | 效果 |
|------|------|
| 闷注 / 跟注 | 补齐到当轮注额。发牌后点「取消」即闷注；看牌后此按钮改为「跟注」 |
| 加注 | 当轮注额 + `_betStep`（上一轮量），不能自选大小 |
| 全下 `AllInBtn` | 先跟齐当轮，再把剩余 HP 全部推进奖池 |
| 弃牌 | 退出争夺，已下 HP 留在池里 |
| 比牌 | 先补齐当轮注额，然后全员亮牌 |
| 看牌 | 进入搓牌，之后自己付 2×。看牌后不再显示闷注 |

加注不够付时，能付多少付多少，视为 **全下**。点「全下」则主动把剩余血量全部投入。

### 5.4 道具（每关各 1 次）

`GameUI` 的 `horBtns2` 上三个按钮始终显示：`PeekGood` / `ChaKanGood` / `TiHuanGood`。下注或搓牌阶段且仍有次数时可点，否则只禁用、不隐藏。

| 按钮 | 效果 |
|------|------|
| PeekGood | 直接再次搓牌（看牌并进入搓牌，可点选一张替换） |
| ChaKanGood | 透视：随机一名存活未弃牌敌人，翻开其随机 1 张牌 |
| TiHuanGood | 替换：自己 3 张牌全部换成牌堆新牌，并视为已看牌 |

### 5.5 连续两轮无人加注

当轮所有能行动的人都已对齐，且连续 2 轮无人加注 → 强制摊牌。

## 6. 全下与摊牌时机（TDA）

炸金花没有公共牌。德州里「继续发翻牌/转牌/河牌」在这里对应 **继续后续下注轮、做边池**。

### 6.1 立刻亮牌摊牌

同时满足：

1. 有人全下（HP=0 且未弃牌、本局已投入 > 0）
2. 本轮能跟的人都已对齐（全下短跟也算完成）
3. **还能继续下注的玩家 ≤ 1**（其余全下或弃牌）

→ 跳过剩余轮次，立刻全员亮牌。

### 6.2 继续做边池

本轮对齐后，仍有 **2 名及以上未全下** 的玩家：

- 不立刻开牌
- 进入下一轮正常跟注 / 加注
- 多出来的投入进入边池
- 已全下的人不再行动，但保留争夺自己参与过的池子的资格

玩家已全下或已弃牌时，由 AI 继续打后续边池轮。

### 6.3 只剩 1 人未弃牌

不比牌，直接无人争夺收走全部奖池。

---

## 7. 主池 + 边池

按 TDA：任何人最多输掉自己投入的 HP。弃牌者已投入的部分仍留在对应池，但不能赢池。

### 7.1 分层

把所有座位的 `TotalBet`（含弃牌）从小到大取不重复档位：

```
主池：min(各人投入) × 投入人数
边池：上一档到下一档的差额 × 达到该档的人数
```

只有 `TotalBet >= 该档` 且 **未弃牌** 的人有资格争该池。

### 7.2 分配顺序

摊牌后从主池开始，按边池生成顺序：

1. 该池资格者里牌型最大者拿走该池
2. 牌型完全相同则平分；除不尽的 1 点给座位最靠前的人（玩家优先）
3. 最小全下者只参与主池；更大投入者可参与更多边池

### 7.3 示例

A 全下 50，B 跟 50 后再下 100，C 同样到 150：

| 池 | 金额 | 资格 |
|----|------|------|
| 主池 | 150 | A、B、C |
| 边池1 | 200 | B、C |

A 牌最大也只能拿主池 150；边池由 B/C 中牌大的一方拿走。

实现：`BuildPotLayers` / `AwardPots`。回血 `Heal`，没有上限。

## 8. 牌型与攻击

### 8.1 牌型（大 → 小）

豹子 > 顺金 > 金花 > 顺子 > 对子 > 散牌

同牌型比点数。`ChipValue`：A=14，其余为点数。这是牌力数值，不是货币。

倍率：豹子 6 / 顺金 4 / 金花 2.5 / 顺子 2 / 对子 1.5 / 散牌 1。

### 8.2 亮牌顺序

玩家先亮 → 弃牌敌人 → 未弃牌敌人。弃牌也会翻开并显示牌型。

### 8.3 攻击伤害

```
伤害 = 牌型基础分 × 当轮注额 × 牌型倍率 × 遗物倍率
```

用当轮注额，不用奖池总量。玩家胜则 `WaitingAttack` 点选敌人；可溅射（瞬劈斩 30%）。玩家败则受赢家一次伤害。

### 8.4 破产 / 斩杀

摊牌后敌人 HP 仍 > 0 但 < `MinBet`：

- 玩家赢：视为斩杀（HP 归 0）
- 玩家输：其他敌人按奖池 15%（铁公鸡 5%）抽血救助

---

## 9. 商店、广告、词缀

击杀本关全部敌人 → 剩余 HP 折金币进商店。

道具 / 遗物见 `GameBalance.Catalog`。遗物最多 4 件。

广告（按钮模拟）：

- 借贷：补 `MinBet`
- 复活：HP 回满
- 额外搓牌：本关最多 2 次
- 双倍金币：每天最多 3 次

第 10、20… 关 BOSS 随机词缀（禁搓花色、禁计分、燧石、锋芒、透视眼、反加注、铁公鸡等）。

连续输 2 局触发「心态崩了」：下一局最大下注为当前 HP 的 50%。

座位字段：

- `Hp`：生命（唯一货币，无上限）；`MaxHp` 仅作开局/复活基准

全下判定：`!Folded && Hp<=0 && TotalBet>0`。

## 11. 改规则时注意

1. 不要再引入独立筹码；`PlayerStartChips` 只用于金币折算。
2. 加注幅度必须等于 `_betStep`（上一轮最终注额），不要按剩余 HP 比例加注。
3. 比牌只跟当轮，不要对齐 `TotalBet`。
4. 我方闷则对手 2×；我方看牌则我方 2×、对手 1×。
5. 全下后若 ≥2 人还能下注，必须继续边池轮，不能立刻摊牌。
6. 结算必须按主池→边池分层，短码全下者不能拿他没投入的边池。
7. `HandScore.BaseChips` / `Card.ChipValue` 是牌力，不是 HP。
